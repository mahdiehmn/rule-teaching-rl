# Executable rule teaching for PPO students

Code, frozen rule banks and appendix sources for teaching reinforcement-learning
students with rules generated by a large language model (GPT-5-mini). A rule
bank is generated once, before training, from a fixed number of consultations.
During training the bank is executed on the student's own predicates and its
recommendations enter PPO as an auxiliary advice loss; no LLM is called while
a student trains, and evaluation uses only the trained policy.

Tasks: MiniGrid DoorKey-8x8, MultiRoom-N6 and KeyCorridor-S3R3 (with larger
variants for transfer) and symbolic Crafter. Students: recurrent PPO and
Count-PPO (PPO with an episodic count bonus).

Maintainer: **mahdiehmn**.

## Layout

| Path | Contents |
|---|---|
| `algos/` | Training loops. `ppo_distill.py` is the MiniGrid trainer with the advice loss; `ppo_crafter.py` is the Crafter trainer. |
| `teachers/` | Teacher interfaces. `teachers/minigrid/rule_bank.py` executes a frozen bank on the student's predicates. |
| `envs/` | Environment registry, observation wrappers and the symbolic Crafter adapter. |
| `advising/` | Action-advising strategies used by the online-advice baselines. |
| `monitoring/`, `integration/` | Evaluation diagnostics and teacher-integration helpers. |
| `scripts/` | Bank construction, experiment launchers, reports and figure scripts. |
| `research/rule_banks/` | The frozen rule banks, including every bank used in the reported experiments. |
| `research/*.md` | Study protocols: design, seeds, arms and decision rules of each experiment. |
| `research/rlingua_controllers_20261005/` | Generated controllers for the RLingua comparison. |
| `configs/` | Run configurations and price tables. |
| `tests/` | Offline tests (no API calls). |
| `paper/appendix/` | LaTeX sources of the paper's appendix. |
| `docs/EXPERIMENTS.md` | Which script and suite produce each appendix result. |

## Installation

```bash
python -m pip install -e .
python -m pip install crafter        # only for the Crafter experiments
cp .env.example .env                 # add OPENAI_API_KEY for bank generation
python -m pytest tests -q
```

Python 3.11 or newer. The launchers target Slurm clusters
(`scripts/submit_*.sh`); each prepares an archived copy of the committed
source before anything is submitted.

Larger MiniGrid maps reuse the source task's bank unchanged. The banks are
frozen: launchers record their SHA-256 in every run manifest.

## Reproducing results

`docs/EXPERIMENTS.md` maps each appendix section to its scripts and suites.
The main training study is `scripts/run_fix_wave_20260929.py` (study id
`fix_wave_20260929_v1`); its protocol, with every suite, seed block and
decision rule, is `research/fix_wave_protocol_2026-09-29.md`. For example:

```bash
python -m scripts.run_fix_wave_20260929 check
bash scripts/launch_fix_wave.sh <repo> dk_fresh mr_fresh kc_fresh
python -m scripts.run_fix_wave_20260929 report --rule-bank <results dir>
```

Bank generation makes paid GPT-5-mini requests; collectors send each frozen
request once under a cost ceiling. Training from an existing bank needs no
API access.

Results, run directories and API journals are written to `results/`, which
is not tracked.
